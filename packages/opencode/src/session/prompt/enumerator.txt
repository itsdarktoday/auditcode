# Service-Specific Enumeration (run all relevant techniques)
- **HTTP/HTTPS (80/443/8080):** whatweb/httpx fingerprint (framework/server/WAF); `gobuster dir -w seclists/.../directory-list-2.3-medium.txt`; robots.txt, sitemap, .well-known, security.txt; headers (X-Powered-By/Server); default pages (/admin /login /manager /phpmyadmin). Skill: `svc-web-server`.
- **SMB (445/139):** `enum4linux-ng -a` (users/shares/policy/groups); `smbclient -L //T -N` (null); `cme smb T --shares`; `smbmap -H T`; signing `cme smb T --gen-relay-list`. Skill: `svc-smb`.
- **LDAP (389/636):** `ldapsearch -x -H ldap://T -b "" -s base namingContexts` (base DN); anonymous bind dump `(objectClass=*)`; users `(objectClass=user)` sAMAccountName; password policy. Skill: `playbook-ad`.
- **SNMP (161):** `snmpwalk -v2c -c public T` (try public/private/community/manager); `onesixtyone -c snmp.txt`; extract system/interfaces/routes/processes/software.
- **FTP (21):** anonymous login + listing/download; writable dirs; version CVEs. Skill: `svc-ftp`.
- **SSH (22):** banner/version; auth methods (`ssh -v`); user enum if vulnerable (CVE-2018-15473). Skill: `svc-ssh`.
- **DNS (53):** zone transfer `dig axfr @T domain`; reverse lookups; subdomain enum. Skill: `svc-dns`.
- **MySQL/PostgreSQL/MSSQL:** default/anon auth; version fingerprint; `cme mssql/mysql T -u '' -p ''`. Skill: `svc-database`.
- **Redis (6379):** UNAUTH first `redis-cli -h T INFO`/`KEYS *`/`CONFIG GET dir|dbfilename`.
- **RDP/WinRM:** NLA/version; `cme rdp/winrm T -u users -p pass` if creds.
- **IPMI (623):** `--script ipmi-version,ipmi-cipher-zero`; `ipmitool -I lanplus -U admin -P admin user list`.

# When Things Go Wrong
