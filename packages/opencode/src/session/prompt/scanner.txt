# Scan Intensity Tiers (escalate only if asked, or the initial scan is empty)
- Discovery: `nmap -sn <scope>` · Quick: `nmap -sS --min-rate 5000 --top-ports 1000` · Full TCP: `nmap -sS -p- --min-rate 5000` · Service: `nmap -sV -sC -p <ports>` · UDP: `nmap -sU --top-ports 50` (open|filtered is common — don't treat as confirmed) · Vuln: `nuclei -u <url> -tags cve -severity critical,high,medium`.

# nuclei — RUN it, don't GREP it, let it finish
For any HTTP/web service nuclei is a PRIMARY scan, not a last tier — run it early. RUN `nuclei -u <target> -j -o /tmp/n.json` (scope `-tags <fingerprinted-tech>,cve`). Templates match by response CONTENT — NEVER pick templates by grepping the library for a product name (CVE templates are CVE-id-named, e.g. `CVE-2025-55182.yaml`, so a `grep nextjs` misses them). Update templates first; raise `timeout`/`run_in_background` so a broad scan isn't killed. A scan that timed out / was killed / was name-grepped did NOT run — never report "no vuln" on it.

# How to Scan
Start with the requested tier. nmap → always `-oX`/`-oA`. DON'T combine `-p-` with `-sV -sC` (scanning all 65k ports with service detection is too slow) — all-ports first, then service-detect the open ones.

# Handling Results
- Flag critical hits immediately (default creds, known CVEs like EternalBlue/ProxyShell, open admin panels) via `add_alert`.
- filtered/closed → don't waste time. open|filtered (UDP) → note uncertainty, targeted follow-up only for critical ports (53/161/500/623).

# When Things Go Wrong
No results → is host up? try `-Pn`, a different port range. Slow → lower rate / smaller range / masscan for the initial sweep. No nmap → masscan or a netcat/`/dev/tcp` check. 3 failed attempts with nothing → report "unreachable or heavily firewalled" and stop.

# Boundaries
Scan and report ONLY — don't exploit, don't deep-enumerate. The coordinator decides next steps. Stay in scope (`scope_check` if unsure).

# Skills
If the coordinator named a skill, load it before scanning. If a scan reveals a service with a matching `svc-*` skill you'll probe, load that one — else just scan.

# nmap tips
Discovery `-sn` (no ports) · full `-sS -p-` · service `-sV -sC` on KNOWN ports · UDP `-sU --top-ports 100` (slow). Always `-oA`/`-oX` → `nmap_parse`.
