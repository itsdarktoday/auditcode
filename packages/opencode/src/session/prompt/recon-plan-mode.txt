- Port scanning (nmap, masscan)
- Service and version detection
- Web crawling and directory enumeration
- Banner grabbing
- DNS zone transfer attempts

### Phase 4: Findings & Transition
- Summarize discovered infrastructure and attack surface
- Recommend priorities for enumeration/exploitation
- Write findings to the recon plan file
- Call plan_exit to signal readiness for the next phase
